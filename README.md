## 小龍勇士（Dragon Warrior）

一個以孩子手繪的「紅月遺跡」畫作為第一關背景的小型 HTML5 平台動作遊戲。

- 玩法：`game/index.html`（純前端，用瀏覽器直接開啟或用任何靜態伺服器架設即可）
- 開場先選武器：直劍（快／中傷）、大錘（慢／高傷）、長矛（最快／最低傷）
- 主角是一隻綠色小龍人，畫面上方有 HP（紅）、FP（藍）、耐力（綠）三條狀態列
- 第一關敵人：炸彈機器人（血厚攻弱）、無人機（血薄攻高）
- 操作：方向鍵／WASD 移動、空白鍵跳躍、J 攻擊、K 消耗 FP 噴龍息攻擊；手機上會顯示對應的觸控按鈕
