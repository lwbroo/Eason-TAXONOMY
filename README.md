## 小龍勇士（Dragon Warrior）

一個以孩子手繪的「紅月遺跡」為靈感、全向量繪製（背景、角色、敵人皆同一卡通風格）的小型 HTML5 平台動作遊戲。

- 玩法：`game/index.html`（純前端，用瀏覽器直接開啟或用任何靜態伺服器架設即可）
- 開場先選武器：直劍（快／中傷）、大錘（慢／高傷）、長矛（最快／最低傷）
- 主角是一隻綠色小龍人，畫面上方有 HP（紅）、FP（藍）、耐力（綠）三條狀態列
- 第一關敵人：炸彈機器人（血厚攻弱，有手腳，會遠距離丟炸彈）、無人機（血薄攻高，會俯衝突擊），攻擊前都會有紅色警示圈＋「!」預告，看到再閃避或防禦。炸彈機器人只會在自己出生的那塊平台上巡邏，不會走到空隙上
- 操作：方向鍵／WASD 移動、空白鍵跳躍、J 攻擊、K 消耗 FP 噴龍息攻擊、L 舉盾防禦（大幅減傷但會消耗耐力、移動變慢）；手機／平板上改用左側的圓形搖桿控制移動，右側則是龍息／防禦／攻擊／跳躍按鈕，會自動貼齊畫面
