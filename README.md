## 小龍勇士（Dragon Warrior）

一個以孩子手繪的「紅月遺跡」為靈感、全向量繪製（背景、角色、敵人皆同一卡通風格）的小型 HTML5 平台動作遊戲。

- 玩法：`game/index.html`（純前端，用瀏覽器直接開啟或用任何靜態伺服器架設即可）
- 開場先選武器：直劍（快／中傷）、大錘（慢／高傷）、長矛（最快／最低傷）；雙刀與巨斧要在村莊的武器商店購買解鎖
- 主角是一隻綠色小龍人，畫面上方有 HP（紅）、FP（藍）、耐力（綠）三條狀態列
- 第一關敵人：炸彈機器人（血厚攻弱，有手腳，會遠距離丟炸彈）、無人機（血薄攻高，會俯衝突擊），攻擊前都會有紅色警示圈＋「!」預告，看到再閃避或防禦。炸彈機器人只會在自己出生的那塊平台上巡邏，不會走到空隙上
- 操作：方向鍵／WASD 移動、空白鍵跳躍、L 舉盾防禦（大幅減傷但會消耗耐力、移動變慢）、1 喝 HP 藥水、2 喝 MP 藥水；手機／平板上改用左側的圓形搖桿控制移動，右側則是 HP瓶／MP瓶／防禦／攻擊／跳躍按鈕，會自動貼齊畫面
- **攻擊系統**：輕點 J 是一般攻擊（耗耐力）；長按 J 則會蓄力放出武器特技（改耗 FP，各武器獨立冷卻）：
  - 直劍－回旋斬：對周圍敵人造成範圍傷害
  - 大錘－投擲重錘：把大錘丟出去，命中沿途敵人後飛回手中
  - 長矛－五連刺：原地快速刺擊 5 下
  - 雙刀－疾風突進：向前衝刺，命中沿途所有敵人
  - 巨斧－大地嘯：範圍比回旋斬更大、傷害更高的重擊，但蓄力較久
  - FP 不會自動回復，只能靠 MP 藥水補充，所以特技要謹慎使用；HP 藥水／MP 藥水皆為每次挑戰限量 3 瓶，用完就要靠一般攻擊撐過去
- **關卡與終點**：每個關卡地圖長度 3000，沿途平台上散落金幣可撿；抵達終點的傳送門會回到村莊
- **敵人造型**：熔岩怪是沒有手腳的液態史萊姆，身體會不斷扭動冒泡、底部有熔岩滴落；火焰法師是披斗篷、拿法杖的人形術士；寄居蟹怪有兩隻大螯與背上多一層蟹殼；極速燕子速度比其他飛行敵人快上許多，尖身分岔尾、拍翼頻率也更快；潛伏藤蔓一開始會埋在土裡只露出葉尖，直到小龍靠近才會破土而出，破土前無法被攻擊到
- **村莊（範圍加大、可走動的安全區，沒有敵人）**：
  - 武器商店：走到商店前按跳躍鍵進入，可裝備已擁有的武器，或花金幣解鎖雙刀（40 金幣）／巨斧（45 金幣），也能在這裡強化目前武器的攻擊力；按數字鍵 1-6 或點擊卡片操作，離開方式：按 J（攻擊鍵）／L／跳躍鍵，或直接點畫面右上角的 ✕ 按鈕
  - 防具商店：另一棟建築，賣護甲（+20 上限HP 並回滿）、HP 藥水袋（+1 瓶上限）、MP 藥水袋（+1 瓶上限），皆可重複購買、等級越高費用越貴；按數字鍵 1-3 或點擊卡片購買，離開方式同上（J／L／跳躍鍵／右上角 ✕）
  - 村莊最深處的大樹可以接任務：走到樹前按跳躍鍵開啟任務板，選擇要挑戰的關卡（按數字鍵 1-4 或點擊卡片；離開方式同上：J／L／跳躍鍵／右上角 ✕）：
    - 🌋 火山關卡：熔岩怪、火焰法師，BOSS 熔岩土龍
    - 🌊 海底關卡：寄居蟹怪、大章魚，BOSS 深海龍王
    - ☁️ 天空關卡：極速燕子、貓頭鷹伯爵，BOSS 飛龍亞基爾
    - 🌿 叢林關卡：藤蔓怪、潛伏藤蔓，BOSS 草神狼
  - 每個關卡的 BOSS 都比一般小怪大上一號，換成專屬的四腳猛獸／飛龍造型（背刺、獸角、發光眼睛、腳下有陰影光環），攻擊時偶爾會多放一次範圍更大的爆發攻擊
  - 金幣、已解鎖的武器、商店強化會在同一輪挑戰中持續累積（換關卡不會重置），按 R 重新挑戰才會全部歸零重新開始
